# 第1回 解答

> 実施環境：講座の想定（Codespaces＋Copilot）ではなく、手元の Mac で実施。演習6のコード改修は、Copilot の代わりに Claude Code を使用した。モデルは既定の `gemini-3.5-flash-lite`。

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  「基礎・応用・発展」という難易度別の3段階で、受講生のスキルに合わせて選ぶもの、と回答した。「レベル2が標準ライン」「無理せずレベル1からでよい」「レベル3はやらなくても減点されないことが多い」と、採点がある前提の説明もしていた。AIE2026 については「AIエンジニア育成講座などの2026年目標のプログラム」と推測していた。
- 用語集の正しい意味と比べて気づいたこと：
  正しくは「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）」で、難易度ではなく取り組みの種類で分かれている。どれか1つに取り組めば完了で、原則として採点しない。モデルは、2つ目の名前（実装→応用）、分け方（種類→難易度）、完了の条件、採点の有無のすべてを外していた。
  一方で「一般的に」「講座によって異なる」と前置きし、資料を確認するよう促してもいた。知らないことを完全に隠しているわけではない。ただ、前置きのあとに具体的でもっともらしい中身を並べるので、講座を知らない人が読むと正解だと受け取りかねない。
- 表示できたトークン数（入力 / 出力）：
  「LoRAとは何ですか？」は 入力 7 / 出力 578、「宿題の3レベル」の質問は 入力 21 / 出力 713。思考（thinking）のトークン数も表示するようにしたが、どちらも 0 だった。

## 宿題

- 取り組んだレベル：基礎
- 使ったモデル：`gemini-3.5-flash-lite`（モデルは変えず、temperature だけを変えた）
- やったこと：
  - `app/ask.py` に `--temperature` オプションを追加し、`generate_content` の `config`（`GenerateContentConfig`）で temperature を渡せるようにした
  - 講座に固有の質問（宿題の3レベル）を、temperature 0.0 / 1.0（このモデルの既定値）/ 2.0 で3回ずつ、計9回実行して出力を比べた
  - temperature の範囲は 0.0〜2.0。Gemini 3.6 Flash 以降のモデルは temperature を無視するため、既定の `gemini-3.5-flash-lite` で実施した
- 結果：

  | temperature | 出力トークン（3回） | 3つの名前 | 示した解釈の数 | 文章の崩れ |
  |---|---|---|---|---|
  | 0.0 | 670 / 498 / 515 | 基礎（基本）・応用・発展 | 1 / 1 / 1 | なし |
  | 1.0 | 603 / 652 / 576 | 基礎・応用・発展 | 2 / 3 / 2 | なし |
  | 2.0 | 545 / 422 / 513 | 基礎・応用・発展（初級・中級・上級） | 2 / 1 / 1 | なし |

  - 0.0 でも、3回とも文章が違った（書き出し、構成、断定の強さ）
  - 1.0 では、難易度別のほかに「AIの活用レベル」などの別の解釈を2〜3通り並べる回が多かった
  - 2.0 でも文章は崩れず、普通に読める日本語だった。AIE を「AI Engineer / AI Expert の略」と推測するなど、ほかの回にない推測が出た
  - 9回とも正解（基礎・実装・発展、どれか1つで完了、採点しない）には届かなかった
  - 出力トークン数には、temperature による一定の傾向は見られなかった
- 気づき・疑問：
  - temperature を 0.0 にすれば毎回同じ答えになると思っていたが、そうならなかった。再現性が必要な用途では、temperature だけには頼れない。
  - temperature を変えても正解には届かず、変わったのは言い回しや話の広げ方だけだった。知らないことは設定では直らず、外から情報を渡す必要がある（第3回のツールにつながる）。
  - 最大の 2.0 でも文章が崩れなかったのは意外だった。既定の top_k / top_p で候補が絞られているからなのか、モデル側の作りによるのかは分からない。
  - 疑問：Gemini 3.6 Flash 以降は temperature が無視されるとのことだが、そうしたモデルで出力のばらつきを抑えたいときは、何で調整するのがよいのか。
