# 第3回 解答

> 実施環境：講座の想定（Codespaces）ではなく、手元の Mac で実施。コードの変更と実行は Claude Code を使用した。モデルは既定の `gemini-3.5-flash-lite`。

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  質問「AIE2026の講座の宿題にある「3レベル」とは何ですか？」で比べた。第1回の `app.ask` は「おそらく難易度別の3段階（レベル1〜3）を指している可能性が非常に高い」と一般論で推測し、正解（基礎・実装・発展）には届かなかった。エージェントは先に `search_glossary` で用語集を引き、「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）の3段階で、どれか1つに取り組めば完了、原則として採点なし」と正しく答え、最後に「関連する回：第1回」を付けた。
- `--trace` で見えたツール呼び出し（ツール名と引数）：
  - 「3レベル」の質問：`search_glossary({'query': '3レベル'})` の1回
  - 「LoRAとQLoRAの違いは？」：`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})`。用語を1つずつ、2回同時に（1回の応答の中で並べて）呼んでいた
- 1つの質問での LLM 呼び出し回数（`requests`）：
  どちらの質問も `requests=2`。1回目でツールを呼ぶと決め、ツールの結果を受け取った2回目で回答を書く。LoRA/QLoRA はツールを2つ呼んだが、同時に呼んだので LLM の呼び出しは2回のままだった。
- 追加したツールと、docstring に書いた説明：
  `make_quiz(lecture: int) -> str` を `app/tools.py` に追加し、`app/agent.py` で登録した。指定した回の用語から `random.choice` で1つ選び、`{"question": "「○○」の意味は？", "answer": 定義}` を返す。用語がない回（第0回など）は「第0回の用語は用語集にありません。用語がある回: 1, 2, 3, 4, 6」と返す。テストを2つ追加した（第2回の用語から出題されること、用語がない回のメッセージ）。
  docstring：
  > 指定した回（1始まりの整数）の用語集から用語を1つ選び、確認問題と答えを返す。
  > 「第2回の確認問題を出して」「復習のクイズを出して」のように、確認問題・クイズ・復習の問題を求められたときに使う。
  > 返り値の answer は出題者用。利用者が答える前に answer を見せないこと。

  「第2回の内容から確認問題を1問出して」で `make_quiz({'lecture': 2})` が呼ばれ、「「QLoRA」とはどのような手法でしょうか？」と、答えを伏せて出題した（`requests=2`）。

## 宿題

- 取り組んだレベル：基礎
- 使ったモデル：`gemini-3.5-flash-lite`
- やったこと：
  `INSTRUCTIONS`（`app/agent.py`）とツールの docstring（`app/tools.py`）を、一度に1か所ずつ書き換え、同じ質問を `--trace` 付きで実行して比べた。各実験のあとは元に戻した（提出するコードは元の指示のまま）。比較の基準（ベースライン）は、演習で `make_quiz` を登録したあとの状態。

  | 実験 | 変えたところ | 変更前 → 変更後 |
  |---|---|---|
  | A | `search_glossary` の docstring | 「query には調べたい用語を1つだけ入れる（例: "LoRA"）」→「調べたい用語が複数あるときは、query にまとめて入れる（例: "LoRA QLoRA"）」 |
  | B | `INSTRUCTIONS` | 「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する」の行を削除 |
  | B2 | B に加えて `search_glossary` の docstring | 「AIエンジニアリングの用語や、この講座（AIE2026）に固有の言葉について答える前に使うこと」も削除（B の結果を受けた追加の確認。2か所を変えた状態） |
  | C | `INSTRUCTIONS` | 「回答の最後に、関係する回（第N回）を示す」→「回答の最後に、確認問題を1問出す」 |

- 結果：

  | 実験 | 質問 | 回数 | ツール呼び出し（引数） | requests | tool_calls | 入力トークン |
  |---|---|---|---|---|---|---|
  | ベースライン | LoRAとQLoRAの違いは？ | 1 | `search_glossary('LoRA')`、`search_glossary('QLoRA')` を同時に | 2 | 2 | 1440 |
  | A | 同上 | 2 | `search_glossary('LoRA QLoRA')` の1回（2回とも） | 2 | 1 | 1141 / 1141 |
  | B | 同上 | 1 | ベースラインと同じ | 2 | 2 | 1392 |
  | B | 3レベルとは？ | 2 | `search_glossary('3レベル')`（2回とも） | 2 | 1 | 979 / 979 |
  | B2 | 3レベルとは？ | 2 | `search_glossary('3レベル')`（2回とも） | 2 | 1 | 919 / 919 |
  | C | LoRAとQLoRAの違いは？ | 2 | 1回目：検索2回 → 結果を見てから `make_quiz(2)`／2回目：検索2回と `make_quiz(1)` を同時に | 3 / 2 | 3 / 3 | 2509 / 1509 |

  - A：検索が2回から1回にまとまった。`search_glossary` は「用語の名前が検索語に含まれる」場合も当たる作りなので、"LoRA QLoRA" で LoRA と QLoRA の両方が返り、回答の中身はベースラインと変わらなかった。入力トークンも減った（1440 → 1141）。1語ずつ検索すると、"LoRA" で「ランク（LoRAのr）」と QLoRA も返り、"QLoRA" で LoRA も返るので、同じ用語が重複して渡っていたため。ただし、結果は最大3件（`MAX_RESULTS`）までなので、4語以上をまとめると取りこぼす作りになっている。
  - B：指示の行を消しても、3回とも検索してから答えた。回答の正しさも変わらなかった。
  - B2：docstring の「答える前に使うこと」まで消しても、2回とも検索した。ツールの説明に残っている「講座の用語集から用語を検索し、定義と、どの回で扱うかを返す」と、質問の「AIE2026の講座の」だけで、モデルは検索を選んでいた。この質問・このモデルでは「必ず確認する」の指示がなくてもふるまいは変わらなかった。
  - C：2回とも、確認問題を出すために `make_quiz` を自分から呼んだ（指示には `make_quiz` の名前を書いていない）。1回目は検索結果で「LoRA は第2回」と分かってから `make_quiz(2)` を呼んだので、LLM の呼び出しが3回に増えた。2回目は検索と同時に `make_quiz(1)` を呼んだため、LoRA の質問なのに第1回の用語（temperature）から出題した。同時に呼ぶと速いが、前のツールの結果を使えない。
  - ほかに気づいた点：ベースラインの1回で、用語集にない「（通常は16ビットなどの精度）」が回答に混ざっていた。ツールの結果をもとに答えていても、モデルが自分の知識で書き足すことがある。
  - 参考：`make_quiz` を登録する前は、同じ LoRA の質問の入力トークンが 1196 だった。ツールを1つ足すと、その説明文の分（この場合 1 リクエストあたり約120トークン）が毎回の入力に加わる。
- 気づき・疑問：
  - 指示を消せばふるまいが変わると思っていたが、検索の指示は消しても変わらなかった。モデルは `INSTRUCTIONS` だけでなく、ツールの名前と説明文からも「いつ使うか」を判断している。指示とツールの説明に同じことを書くと、片方を消しても効いて見えないので、どちらが効いているのかを確かめるには両方を見る必要がある。
  - 逆に、docstring の1文（「1つだけ」→「まとめて」）では、引数の作り方がはっきり変わった。引数の入れ方はツールの説明文で決まりやすい。
  - 「確認問題を出す」とだけ書いても、モデルは合うツール（`make_quiz`）を自分で探して使った。一方で、引数を決める材料がそろう前にツールを同時に呼ぶと、回を取り違えた。順番が大事な処理は、指示で「検索の結果を見てから出題する」と書く必要がありそう。
  - 同じ指示でも、呼び方（同時か順番か）が回ごとに変わった。1回の実行だけでは「変わった／変わらない」を言い切れない。
  - 疑問：指示を消しても検索するなら、「必ず確認する」の行は何のためにあるのか。もっと性能の低いモデルや、用語集に関係なさそうな言い回しの質問では、この行の有無で差が出るのか。
